# 2026シルバーウィーク行き先比較

2026年シルバーウィーク（9/19土 – 9/23水）の予定を提案する静的サイト。
**水戸発・2人・合計4万円前後**という条件で、10方面の旅程と予算内訳をまとめています。

ページ上部の方面ピルで行き先を切り替えられます。

- **茨城**（既定表示）— 5日間フルの旅程。「旅程」「予算」「差し替え」「準備」の4タブに分かれています
- **山形**（蔵王・山寺）／**新潟**（越後湯沢・谷川岳）／**福島**（磐梯高原・猪苗代）／**伊豆**（熱海・城ヶ崎）／
  **日光**（東照宮・華厳の滝）／**草津**（湯畑・熱帯圏）／**南房総**（濃溝の滝・野島埼灯台）／
  **松島**（日本三景）／**軽井沢**（旧軽井沢・アウトレット）— それぞれ1泊2日の弾丸プラン

予算は2人合計4万円前後で統一（距離が最長の松島のみ4万5千円とやや高め）。遠い方面ほど交通費の比率が上がり、
水戸からの実際の運賃相場・高速料金検索結果をもとに見積もっています。

交通手段は方面ごとに安いほうを選び、旅程・予算表ともその前提で組んでいます。

| 方面 | 前提 | 交通費（2人往復） |
| --- | --- | --- |
| 茨城 | 車 | ガソリン・駐車のみ |
| 山形 | 車 | ¥18,500 |
| 新潟 | 車 | 概算 ¥16,400 |
| 福島 | 車 | 概算¥13,500（9方面で最安） |
| 伊豆 | **電車** | ¥17,000（車だと概算¥19,800で割高） |
| 日光 | 車 | ¥9,700 |
| 草津 | 車 | ¥13,800（高速区間＋一般道） |
| 南房総 | 車 | ¥16,860 |
| 松島 | 車 | 概算¥15,100（9方面で最遠・約255km） |
| 軽井沢 | 車 | ¥14,500 |

各方面には選ばなかったほうの交通手段の試算も併記してあります。
高速料金は山形・日光・草津（高速区間）・南房総・軽井沢が実際の料金検索結果、
福島・新潟・伊豆・松島は距離からの概算。ガソリン代は燃費15km/L・175円/Lで統一して計算しています。

宿泊費はTripadvisor経由（2026年9月19日泊・2人1室）の実勢価格で補正済みです。
これにより合計は方面ごとに2人4万円〜4万5千円の幅があります（茨城・福島・南房総は4万円ちょうど、
山形4万500円、新潟4万1,000円、日光4万1,500円、軽井沢4万1,000円、草津・伊豆4万2,000円、松島のみ4万5千円）。
伊豆の予算表では当初、現地の昼食代3,000円が集計から漏れていた誤りも修正しました。
松島は町自体が小さくシルバーウィーク中の宿泊需要が極端に高いため、宿泊先を松島の町なかから
仙台市内に変更して現実的な予算に収めています（詳細はサイト内の該当方面を参照）。

## 中身

| ファイル | 説明 |
| --- | --- |
| `index.html` | サイト本体。CSS・JS（方面/タブ切替、約110行）とも埋め込み、外部依存なし |
| `images/` | 掲載写真51点（ウィキメディア・コモンズ、いずれも自由ライセンス） |
| `build_artifact.py` | 画像をdata URI化した1枚のHTMLを生成するスクリプト |

## 見る

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html` をブラウザで直接開いても表示されます。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
ブランチのルートを指定すればそのまま動きます。

## プランの前提

- 出発地は水戸、移動は車（燃費15km/L・ガソリン175円/Lで概算）
- 4万円は**2人合計**
- 宿泊は9/21（月）泊の1泊のみ。前後は日帰りを重ねる構成
- 料金・営業時間・開催日は2026年8月時点で各施設や自治体が公開している情報にもとづく見積もり

## 単一ファイル版を作る

```sh
pip install Pillow
python3 build_artifact.py
```

`dist/silver-week-2026.html` に、画像を埋め込んだ自己完結型のHTMLが出力されます。
メールで送る、USBで渡すなど、`images/` を一緒に持ち歩けない場面向けです。
