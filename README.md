# 2026シルバーウィーク行き先比較

2026年シルバーウィーク（9/19土 – 9/23水）の予定を提案する静的サイト。
**水戸発・2人・合計4万円**という条件で、5方面の旅程と予算内訳をまとめています。

ページ上部の方面ピルで行き先を切り替えられます。

- **茨城**（既定表示）— 5日間フルの旅程。「旅程」「予算」「差し替え」「準備」の4タブに分かれています
- **山形**（蔵王・山寺）／**新潟**（越後湯沢・谷川岳）／**福島**（会津）／**伊豆**（熱海・城ヶ崎）— それぞれ1泊2日の弾丸プラン

どの方面も予算は2人合計4万円で統一。遠い方面ほど交通費の比率が上がり、
水戸からの実際の運賃相場（在来線・高速バス中心、新幹線や特急はなるべく避ける前提）をもとに見積もっています。

山形・新潟・福島・伊豆の各方面には、電車ルートに加えて「車で行く場合」の比較（高速代・ガソリン代・所要時間）も
載せています。会津（福島）と山形は実際の高速道路料金検索の結果、新潟・伊豆は概算です。
福島だけは車のほうが電車より安くて速く、伊豆は逆に車のほうが高くつく可能性がある、という結果になりました。

## 中身

| ファイル | 説明 |
| --- | --- |
| `index.html` | サイト本体。CSSは埋め込み、JavaScriptなし |
| `images/` | 掲載写真17点（ウィキメディア・コモンズ、いずれも自由ライセンス） |
| `build_artifact.py` | 画像をdata URI化した1枚のHTMLを生成するスクリプト |

## 見る

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html` をブラウザで直接開いても表示されます。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
ブランチのルートを指定すればそのまま動きます。

## プランの前提

- 出発地は水戸、移動は車（燃費15km/L・ガソリン175円/Lで概算）
- 4万円は**2人合計**
- 宿泊は9/21（月）泊の1泊のみ。前後は日帰りを重ねる構成
- 料金・営業時間・開催日は2026年8月時点で各施設や自治体が公開している情報にもとづく見積もり

## 写真について

掲載写真はすべてウィキメディア・コモンズの自由なライセンス（CC BY / CC BY-SA / パブリックドメイン）の作品です。
撮影者とライセンスは各写真のキャプションおよびページ下部のクレジット欄に記載しています。
写真を差し替える場合は、同じ形式でクレジットを更新してください。

## 単一ファイル版を作る

```sh
pip install Pillow
python3 build_artifact.py
```

`dist/silver-week-2026.html` に、画像を埋め込んだ自己完結型のHTMLが出力されます。
メールで送る、USBで渡すなど、`images/` を一緒に持ち歩けない場面向けです。
